## Eventory Backend

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/EventoryHost/Eventory-backend.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Eventory-backend
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Usage

1. Start the server:
   ```bash
   npm run dev
   ```
2. The API will be available at `http://localhost:4000`.
