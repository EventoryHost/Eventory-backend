               SUMMARY OF CHANGES - ANONYMOUS CUSTOMER CHAT BACKEND

1. Models Updated
   - models/chats.js:
     - Added "anon_customer-admin" to chat_type enum.
     - Added "anon_customer_id" field.
     - Made customer_id, vendor_id, and service_id optional to accommodate anonymous chats.
   - models/message2.js:
     - Added "anon_customer-admin" to chat_type enum.
     - Added "vendor_card" to message_type enum.
     - Added "anonymous_customer" to sender enum.

2. New Controller Created
   - controllers/anonChatController.js:
     - sendAnonymousMessage: Handles sending messages from anonymous users. Automatically creates a new chat if one doesn't exist and triggers a Slack notification.
     - getAnonymousMessages: Retrieves chat history for a specific anonymous customer ID.
     - getAnonymousChatStatus: Checks if an active chat exists for an anonymous customer.

3. Existing Controller Updated
   - controllers/chatController.js:
     - Updated validation logic in handleSocketConnection, getMessagesByChatId, searchMessages, etc., to allow "anon_customer-admin" chat type.
     - Added "anonymous_customer" to allowed senders where appropriate.
     - Updated WebSocket events (`join_chat`, `send_message`) to fully support anonymous customers.
     - This ensures the existing Admin Portal can view and reply to these new chats without major frontend changes.

4. New Routes Created
   - routes/anonChatRoutes.js:
     - POST /message
     - GET /:anon_customer_id/messages
     - GET /:anon_customer_id/status

5. Routes Registered
   - routes/routes.js:
     - Imported and registered anonChatRoutes at "/api/anon-chats".

6. Slack Integration
   - utils/slackNotifier.js:
     - Added sendSlackAnonChatMessage function to send a notification to the configured Slack channel when a new anonymous chat is initiated.

7. WebSocket Integration
   - Enabled real-time messaging for anonymous users via `socket.io`.
   - Updated `chatController.js` to handle `join_chat` and `send_message` events for `anon_customer-admin` chat type.
   - Added logging for anonymous chat joins.

8. Documentation & Guides
   - Created `frontend_integration_guide.txt` to assist frontend development with API usage, WebSocket flows, and data mapping.

9. Verification
   - Created `test_anon_chat.js` to verify the complete flow (REST + WebSocket).
   - Verified chat creation, message history retrieval, and real-time messaging.

10. Meta Ads Integration & Anonymous User Tracking
    - Created `models/anonymousUser.js`:
      - Stores anonymous user data with `anon_id` (format: `ANON...`).
      - Tracks acquisition parameters (`fbclid`, `utm_campaign`, etc.).
      - Tracks device info (`ip_hash`, `user_agent`, etc.).
      - Tracks `first_seen_at` and `last_seen_at`.
    - Created `controllers/anonymousUserController.js`:
      - `initializeAnonymousUser`: Generates/Returns `anon_id`, saves user data, and sets HTTP-only cookie.
      - `updateAnonymousUserActivity`: Updates `last_seen_at` for heartbeat.
    - Created `routes/anonUserRoutes.js`:
      - `POST /api/anon-users/init`
      - `POST /api/anon-users/:anon_user_id/heartbeat`
    - Integration:
      - Updated `controllers/anonChatController.js` to update `AnonymousUser` activity (`last_seen_at`) whenever a message is sent.

11. Slack Notification Updates
    - Updated `utils/slackNotifier.js`:
      - Added check for `IS_LOCAL` environment variable.
      - Skips sending notifications to Slack if `IS_LOCAL=true` to prevent spam during development.

12. Admin Notification API Identification
    - Identified endpoints for marking admin notifications as read:
      - `PATCH /api/em-notifications/read/:notificationId` (Single)
      - `PATCH /api/em-notifications/:em_id/mark-all-read` (All)
